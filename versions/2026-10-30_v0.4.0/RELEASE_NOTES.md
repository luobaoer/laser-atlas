## 课程与设计器

- 新增独立章节「从 ABCD 矩阵到腔内各元件的位置设计」，保留原章节 ID 和学习进度。
- 以 Nd:YVO₄、AOM、M2、THG、SHG、M3 为教学拓扑，六段空气间隙 d1–d6 均可修改；材料厚度与有效折射率分开输入。
- 支持 M1/M2/M3 曲率（0 为平面）、M2 入射角及切向/弧矢像散、晶体内任意位置的等效热透镜及可选的腔内额外薄透镜（可选间隙和位置）。
- 采用 `[y,nθ]` 状态，空气/晶体厚度通过 `P(d/n)`，镜片通过曲率矩阵，完整反射往返链求稳定性及自洽 `q̃`；仅在存在稳定本征模时计算光斑。
- 默认给出 15 个关键参考面，包括增益/AOM/THG/SHG 的前面、中心、后面与 3 个腔镜；启用额外薄透镜后为 16 面。
- 输出 T/S 两轴 `w`、波前曲率 `Rw`、约化 `q̃`、局部瑞利长度和相对束腰位置，支持热透镜扫描、可选参考面和孔径比提示。
- 支持浏览器本地参数保存、参数 JSON 导入导出及全表 CSV 导出。
- 教学模型：仅用于 1064 nm 近轴 Gaussian TEM00 腔模，**不能预测 532/355 nm 转换、增益、动态调 Q 或损伤阈值**。默认参数是教学例子，非实测工业机参数。

## 核查

- 12 组物理和数值检验：双镜腔解析解、detM=1、q 自洽、T/S 同角退化、M2 像散、晶体参数、热透镜与额外透镜位置变化、平平边界、热扫描失稳段等。
- Chromium 桌面（1440px）和手机（390px）：章节内容、调参引起光斑重算、表面选择、额外镜片、失稳提示及移动端横向溢出均已检查。
- 版本历史机制不变：`versions/YYYY-MM-DD_v.../` 归档首页及工具，根目录首页和工具为当前发布版。
