# Laser Atlas · 激光器设计学习平台

Laser Atlas 是面向光学工程学习与教学的移动端友好网站，按照固体、光纤、CO₂、蓝光四类激光器的工程设计流程组织内容。

## GitHub Pages 部署

仓库主页打开 **Settings → Pages → Build and deployment**，选择 **Deploy from a branch**，再选择 **main / (root)** 并保存。

预期网址：https://luobaoer.github.io/laser-atlas/

## 内容

- 激光器完整设计流程课程
- 355 nm 腔内频率转换与折叠腔入门
- 专业术语点击解释和公式符号手册
- 手机交互计算器、学习记录与个人笔记

网站为静态 HTML，无需 Python 或服务器；学习进度储存在当前浏览器，不能自动同步。内容仅供学习，不作为实际激光器的工程认证或安全证明。
